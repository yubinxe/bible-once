# CONTENT GUIDELINES

## 1. 원본과 해설의 분리
- **공식 정보**(제목·본문·강사·일정): 출처 값 그대로. 각 항목에 `status`와 `sourceIds`.
- **설교 요약**(`editorSummary`): 공식 영상·원문을 사람이 확인한 뒤에만, 3줄, `basis`(근거) 필수, `review: reviewed`일 때만 게시(검사기가 강제).
- **본문 연구**(`study`): 성경 본문에 대한 편집 해설. 설교 내용을 요약·대변하지 않는다고 화면에 명시.
- 두 강사의 설교를 하나로 합치지 않는다.

## 1-1. 설교 노트(AI 전사 요약)
- 원천: 사랑의교회 공식 채널의 설교 영상 자막. 채널명과 업로드일(10.19–25)을 검증하고, 맞지 않으면 중단한다.
- 산출: 3줄 요약 · 설교의 흐름(타임스탬프) · 인사이트(편집 해설) · 언급된 다른 본문 · 적용 · 기도 · 확인 필요 사항.
- 직접 인용 금지(12자 이내 예외), 사적 개인 실명 금지, 전사문에 없는 내용 생성 금지.
- 전사문에 없는 타임스탬프는 제거하거나 ‘확인 필요’로 표시한다.
- 화면에는 항상 ‘AI 전사 요약 · 검수 전’과 원본 영상 링크를 함께 표시한다. 사람이 영상과 대조한 뒤 `review: "reviewed"`로 올린다.

## 2. 3-Layer Interpretation
1. Plain — 쉬운 한국어, 단 본문의 긴장을 지우지 않는다.
2. Context — 저자·수신자·역사·장르·전후 문맥.
3. Theology — 그리스도 중심, 은혜와 구원, 성령, 제자도. 직접 본문과 해석을 구분하고 편집자 관찰은 "(편집자 관찰)"로 표시.

## 3. 시각화
서사 본문은 `narrative-sequence`. 시·서신은 장면화하지 말고 `argument-map`·`thematic-progression`·`literary-structure`. 선택 본문 밖 노드는 `context: true`(점선).

## 4. 인용과 저작권
- 개역개정 핵심 구절 1절 이내(검사기가 범위 표기를 거부). 전문은 대한성서공회 링크.
- 원문 대조 전 인용은 "원문 대조 검수 대기" 캡션 유지.
- 설교 영상·음원·뉴스레터·사진 재배포 금지. 실제 교회 사진처럼 보이는 생성 이미지 금지.

## 5. 검수 상태
`draft` → `needs-review` → `reviewed`. AI 보조 초안은 사람 검수 없이 `reviewed`가 될 수 없다. 검수 시 DECISIONS.md에 검수자·일자·범위를 남긴다. 공식 값 변경 시 연관 해설은 `needs-review`로 되돌린다.

## 6. 문체
담백하고 정확한 한국어. 과장·마케팅 어휘·세속 브랜드 언어 지양. 성경·은혜·회개·구원·성령·제자도·기도·찬양의 언어를 우선.

## 7. 개인 정보
기도·묵상은 localStorage에만. 개인 기도요청·실명 간증·성도 게시글은 수집·게시하지 않는다.
