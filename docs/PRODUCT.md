# PRODUCT — THE DAWN

> 특새의 감동을 그날 새벽에만 머물게 하지 않고, 말씀을 이해하고 기억하며 삶에서 실천할 수 있는 여섯 날의 영적 여정으로 만든다.

## 정의
- 사랑의교회 제24차 가을 글로벌 특별새벽부흥회(2026.10.19–24)의 **독립 Scripture Companion**.
- 공식 홈페이지를 대체하지 않는다. 공식 자료는 출처로 연결하고, 본 서비스는 이해·기억·묵상을 돕는다.
- 교회 공식 서비스나 후원을 받은 것처럼 표시하지 않는다.

## 사용자 여정
1. 입장 — 예배당 문이 열린다(세션당 1회, 건너뛰기 가능, reduced-motion 시 생략).
2. 오늘 — 홈에서 오늘의 날·설교·본문으로 진입.
3. 이해 — 본문 → 역사적 배경 → 논리 구조 → 신학적 의미.
4. 기억 — 기억 인출 · 본문/해석 구별 · 한 문장 설명 · 전날 회상.
5. 묵상 — 깨달음 / 질문 / 기도 / 실천을 이 기기에만 기록.

## 정보 구조
| 경로 | 역할 |
| --- | --- |
| `/` | Sacred Hero · 여섯 날 · 오늘의 말씀 · 신학 인사이트 · 묵상 · 공식 아카이브 |
| `/revival` | 6일 통합 일정과 상태 |
| `/revival/[date]` | 일별 9섹션 경험 |
| `/sermons`, `/sermons/[id]` | 강사별 독립 본문 연구 |
| `/reflection?date=` | 비공개 묵상 기록 |
| `/archive` | Source Registry · 확인 상태 |
| `/about` | 정체성 · 고지 · 저작권 · 개인정보 |

## 하지 않는 것
연속 출석 압박, 점수·랭킹, 중독적 보상, 공개 기도 게시판, 설교 전문·영상 재배포, 검증 없는 설교 요약.

## 우선순위 (현재 상태)
1. 실제 특새 데이터와 연결된 홈 — 완료
2. 6일 통합 일정과 공식자료 — 완료(3–6일차 일부 공식 업데이트 대기)
3. 10.19·10.20 설교 학습 화면 — 완료(본문 연구 · 검수 대기)
4. 시각적·논리적 학습 인터페이스 — 완료(FlowMap 4종)
5. 기도와 묵상 — 완료(localStorage)
6. 공식자료 갱신 절차 — 수집기 + 예약 워크플로 + 수동 보완(SOURCE_REGISTRY 참조)
